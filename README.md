# ReceiptAnalyzer Mobile

영수증 이미지를 Google Drive 대기함으로 전송하는 모바일 클라이언트입니다.

- iPhone: GitHub Pages 주소를 Safari로 열고 `공유 > 홈 화면에 추가 > 웹 앱으로 열기`를 선택합니다.
- Android: GitHub Releases의 APK를 설치하거나 Chrome에서 홈 화면에 추가합니다.
- 최초 사용: 데스크톱 ReceiptAnalyzer의 `모바일 앱 설치·연결` QR을 스캔합니다.

저장소와 빌드 결과에는 Google Drive 인증키가 포함되지 않습니다.
